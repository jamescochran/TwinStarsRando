Rules FAQ

General

If you win by performing an action that requires a skill check, do you win immediately or perform the check first?

You need to perform the skill check and suffer any consequences first.

When a character has multiple symbols on the same row and two combos are possible simultaneously, how do you decide which to activate?

You can choose which of the possible combos to activate.

When multiple symbols on the same row form a combo, can you avoid it by choosing a symbol that wouldn't activate it?

If a combo is formed, you must activate it — unless there's another combo that can be activated instead.

When can you use the universal special ability to re-roll a die? Only when placing dice on characters, or also for skill checks and scenario rolls?

Energy can be used to re-roll any die at any time, unless a special rule states otherwise (e.g., in Hunt the Bounty, search dice can only be re-rolled using resources rather than energy).

What is the sequence of events when activating a reaction or fatigue ability?

If no combo results from a roll, pick one die to reduce and one to re-roll. Reduce the die first. If there is a fatigue or reaction ability on the space you reduced to, resolve it. If no combo results from that, pick up the other die and re-roll it as usual.

For a skill check, what happens if one die fits the range and the other doesn't?

Unless both dice can fit, you fail the skill check.

If a combo doesn't occur, one die is reduced and the other re-rolled. If a combo still doesn't occur, must the same die be reduced again?

You can always choose which die to reduce and which to re-roll.

Can you place both character dice on the same character?

No; you can only place one die on each character, unless a special rule states otherwise.

When gaining or losing health, can you choose which character is affected?

If the icon is on a character, that character must be affected. If the icon is on the scenario or part of a skill check, either character may be affected — unless stated otherwise.

Do all special abilities require energy to use?

No. The universal special is to re-roll a die by spending energy, and many others require energy too. But if a special does not have an energy cost, it activates in some other way instead.

Characters

Bood

Can Bood's special action be used to re-roll skill check dice, or only character dice?

No; only energy can be used to re-roll skill check dice.

When using Bood's special action to re-roll dice, can they be re-rolled one at a time or only together?

Whenever both dice are rolled, they're always rolled together; Bood is no different.

Brenimov-X

How do you get the star on Brenimov-X's 2-spot?

If you roll a two, you need to re-roll the die. However, effects do not activate upon die reduction — so if you reduce the die to two, it stays there.

Fanoobia

When reducing to Fanoobia's one-spot, can you choose which character to heal?

No; Fanoobia can only heal herself.

Grant Rockgardner

Does Grant's special ability work for any die roll, or does he roll a special die after activating it?

Grant can spend energy to call the number of a die rolled during regular gameplay — it's an excellent insurance policy against a roll that, if it fails, will sink you.

Can Grant's special ability be used to call two dice being rolled at once?

No; when rolling two dice, they are always rolled together, and Grant's ability can only be activated when rolling "a die."

Inpon Gol

Does Inpon Gol's token move every time the die is removed from his 3-spot?

No; any time the die is on the 3-spot and is then re-rolled or reduced, the token moves to the other side of the spot.

When does Inpon Gol lose health — when the die is moved to his 3-spot or when it's moved off?

If the broken heart is uncovered and the die is placed on Inpon's 3-spot, he immediately loses health.

Inzill Mey

When using Inzill Mey's instant action to place the other die on any number and re-roll this die, which die goes where?

You can place Inzill's partner's die on any spot on Inzill's partner. Then pick up Inzill's die and re-roll it on her card.

When using Inzill Mey's instant action to copy another character's instant action, which character actually uses it?

Inzill Mey adopts the other character's instant action and uses it as if it were her own.

Kinglan

After placing a coin heads-up on Kinglan's card, is the coin removed after it's used in place of a flip?

Yes; it's a one-time effect. The next time a coin flip is needed, it must be flipped randomly as usual.

If a coin is already on Kinglan's card heads-up when the effect is activated again, what happens?

The effect is redundant and ignored. You only need one coin for the game.

Phaeton

With Phaeton in play, !! counts as a combo but !!! does not. What about !!!!?

Only !!! does not count as a combo; !!!! counts the same as a regular !!.

Roux Jaezmina

When using Roux's instant action (re-roll both dice, add them, make two new dice with the same sum), must both new dice show the same number?

No; get the sum and split it between the two dice any way you choose.

Smiff

How does Smiff's "Focus *" work?

If a skill check succeeds and Smiff's die is a three, you gain a * icon; if the other die is already on a *, it counts as a ** combo. Otherwise, continue play as normal.

Strezelsior

When combining both dice, using the sum, and re-rolling the other die — which die uses the combined number and which is re-rolled?

You can choose which character to place the set die on and which character to re-roll.

What happens if the two dice add up to more than six when using Strezelsior's special action?

You can only use this ability when the dice combine to a sum of six or less.

Yanfred Jima

Do both dice need to be on !! to activate Yanfred's special?

No; the special can be activated at any time. Take the effect of a !! combo as shown on the scenario card, then swap the positions of the dice. You may then activate any instants or combos achieved through the swap, after the !! has taken effect.

Doesn't activating a combo (including !!) normally return the dice to your hand?

Normally yes; this ability, however, activates a combo and then allows the dice to be manipulated after as part of the action.

Zoaze

What do the "re-rolls" in Zoaze's special action refer to?

Anytime you use Zoaze's reaction abilities on her one- and two-spots, you may add one to the result of the die roll in exchange for conducting a skill check.

Scenarios

Scenario 01: Escape the Brig!

Do you need to acquire the Pick (with a ** combo) before you can use it?

Yes; the pick is covered at the start of the game. Use a ** combo to uncover it and then use it at will.

If you get a *! combo without having acquired the pick, are you forced to perform the "Advance forward 1 space and [Skill -2 Health]" action?

No; you can't use the pick in the first place, so *! does not count as a combo.

If you acquire the pick and later choose to drop it, is it permanently removed from the game?

No; it returns to its spot on the scenario card and can be reacquired with another ** combo.

Scenario 02: Confine the Quarks!

Do base precision and precision begin at the same spot at the start of the scenario?

Yes, they both share the first spot on the precision track.

Can precision ever be below base precision?

No; it cannot be reduced below base precision. If it's at the same position as base precision when base precision increases, it increases as well.

Do the bonuses on the precision track apply during any die roll, or only when experimenting?

The precision track applies only when experimenting.

"May re-roll 1 if experimenting" — does this mean one die may be re-rolled, or a die showing "1"?

All dice showing "1" may be re-rolled when experimenting. If no dice roll a one, no dice may be re-rolled through this ability.

"May use 5 and 6 for +$1M" — does a five and a six each increase funding, or only the combination?

Only a combo of one five and one six increases funding by $1M.

When rolling a 5 and 6 grants additional funding, does that experiment still count as a failure?

No; the funding is gained and that experiment action ends — neither a success nor a failure.

"Evens = +1 at Pentaquark" — what rolls add a quark?

Doubles are normally required. Once this track point is reached, a roll of two even numbers (e.g., 2 and 4) also yields one quark.

Scenario 03: Rule the World!

Are the enemy ships covered at the start of the scenario?

No; the enemy ships begin uncovered and ready to attack.

Scenario 04: Stop the Virus!

When using the check-check combo to cover a virus, if you roll the number of the marked virus, can you cover the marked virus?

Yes, you got a lucky roll.

Does the required roll for a healing attempt continue to scale beyond what's stated on the card?

No; you get no additional bonuses for covering up more viruses than the card states.

What does it mean to "treat" the marked virus?

The marked virus is "treated" by being covered up — either through a ** combo or by a check-check combo roll.

Does a "healing attempt" let you cover up the marked virus?

No. "Treating" the marked virus has nothing to do with healing attempts. Successful healing attempts either heal or restore stamina; they do not interact with the virus row.

Scenario 05: Steal the Plans!

At the start of the scenario, how many guards begin at the Guard Start location?

Just one; others may appear later.

Can player characters move only clockwise, or in any direction?

Players can move in any direction.

If a character moves on top of a guard (rather than a guard moving onto a character), does it still count as a capture?

Yes; the scenario ends in failure.

If there are already four guards and a fifth is summoned, what happens?

Nothing; there can be a maximum of four guards in play at any time. If a guard is eliminated, that token can be re-used to spawn a new guard later.

What does it mean that guards see "in a straight line"?

Guards standing on the edges of the card can see to the ends of the same edge. They cannot look around corners or across the text on the card.

If you move twice while carrying the plans and pass over a spot that generates guards without stopping, do guards still appear?

Yes; the plans passed through that spot and new guards appear at their starting location.

Scenario 06: Hunt the Bounty!

How many resources do you start with?

Both characters start with full health. You choose how much energy to begin with (depending on your preferred difficulty). You start with five supplies (also the maximum).

What do the "Inquiry" and "Restock" actions accomplish?

After placing both characters, both dice are rolled. If the combined total matches the condition on the planet where a character performed an inquiry, the stated information is gained; otherwise the stated threat is gained. If either or both dice fit the restocking character's skill check range, you gain one resource of your choice; if neither fits, nothing happens.

Do you lose if you reach the end of the threat track?

No; you can only lose by losing all health on one character. However, a full threat track reduces health so much for every !! combo that you probably won't last much longer.

Do you win if you reach the end of the information track?

No; you can only win by capturing the bounty. However, it is highly unlikely you can do so without reaching near the end of the information track.

How do you "spend resources" to attempt to capture on a ** combo?

Resources — energy, health, and supplies — are expended to add to the capture die roll and the information track in any amount you choose. Each resource spent adds one to the roll and is then lost.

Scenario 07: Master the Trials!

What does it mean that you must take a skill check "at each reduction"?

Each time the die is reduced (due to not activating a combo), you must also take a skill check and lose a health point (on the character that reduced a die) in case of failure.

How does the difference between the Master's and Apprentice's levels affect attempting a trial?

To attempt a trial, roll one die — if it's equal to or greater than the number on the next trial spot, you succeed. If using the check-check combo, subtract the difference between the Master's and Apprentice's levels from your roll. (For example, if both are at their starting locations, subtract three.)

Scenario 08: Beat the Odds!

The description says to use five coins, but the scenario side says six. How many?

Five; the scenario side is incorrect. The scenario is a "best out of five" contest — the first to win three coins wins.

When the thieves have moved a coin to their track, can it still be recovered?

Yes; a ** combo lets you steal a coin back as long as it's still on the thieves' track. Once moved to the "X," it is permanently lost.

What does it mean to "gain a re-roll" under the ** combo?

Use a ** combo to mark one of the four positions on the "re-roll" track. Thereafter, when betting, if your combined roll equals that marked number, you may choose to re-roll (and take the skill check if necessary). The re-roll track only comes into play while betting.

Scenario 09: Control the Skies!

When beginning, do you place your character token first or the enemy starfighter first?

You must begin by placing a token for your characters, then place the enemy starfighter after.

When a new wave of enemies hits, can you re-place your ship for free?

No free move; if you'd like to move, you must activate a check-check combo first.

If using a check-check combo to move onto a location where an enemy fighter is located, can you choose to move without attacking?

No; if activating a check-check combo and you can destroy a fighter, you must do so.

How do you use the upgrade track?

Each ** combo lets you move the upgrade token forward. When you advance to the missile, take the missile token; when you advance to the shield, take the shield token. When you reach the end, you may move back to the beginning for free. Alternatively, a ** combo can deploy a missile or shield token you've already acquired instead of advancing.

Could you theoretically gain a shield on every spot or build up a limitless stock of missiles?

No; there is only one shield token and one missile token. Once acquired, they cannot be re-acquired until used.

Scenario 10: Sell the Junk!

At the very start, do you begin with $0 or $1?

You begin with $1, and place the token on the money track accordingly.

Does the money track intentionally skip from $8 to $10, and from $10 to $12?

Yes; you must gain $2 to make those jumps. A single dollar gained when you're already at $8 (or $10) is wasted.

Scenario 11: Destroy the Order!

After passing a law, are you required to follow it in all cases or can you choose when it applies?

If a law is in effect, it must be followed whenever applicable.

What constitutes "using" a law?

A law is "used" only when a combo is activated that is in some way modified by the law. An icon that does not result in a combo does not count as a use.

Scenario 12: Serve the Rabble!

Do the primary and secondary character tokens placed on "bouncer" and "server" ever move or interact with the scenario?

No; they are simply there to mark which character acts as which.

What is the difference between the server and the bouncer?

The bouncer begins with one additional health point on top of the character's usual maximum. The server can at any time sacrifice one health to gain one energy.
